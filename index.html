1.1 運算思維的四大核心支柱 (Computational Thinking)

運算思維（Jeannette Wing 提出）並非單純學會寫程式，而是利用電腦科學的概念來解決問題的思考邏輯過程。包含以下四個不可或缺的階段：

01

拆解問題 (Decomposition)

將複雜大問題剖析、分解為數個較小、可單獨處理的子問題。

02

發現規律 (Pattern Recognition)

觀察資料中重複出現的趨勢、特徵或規律性，找到共同模式。

03

歸納抽象 (Abstraction)

過濾非必要的細節，聚焦於核心公式與一般性運作原則。

04

設計演算法 (Algorithm)

規劃出解決問題的明確步驟流程，讓電腦得以自動精確執行。

1.2 Python 語言核心優勢

  • 直譯式 (Interpreted)：無需預先編譯即可透過 Python 直譯器逐行執行，除錯測試極其快速。
  • 動態型態 (Dynamic Typing)：變數不需事先宣告資料型態，記憶體指派由直譯器於執行期動態處理。
  • 高階豐富生態系：內建 Batteries-Included 理念，並支援數百萬第三方套件 (NumPy, Pandas, SciPy)。

2.1 變數本質與記憶體指派機制 (Memory Concept)

在電腦底層，記憶體位置是一串十六進位位址（例如 0x7ffe567a）。在 Python 中，「變數」並非像傳統 C 語言是固定的盒子，而是指向記憶體中物件的**標籤 (Reference/Pointer)**。

【互動元件】Python 記憶體指派與變數綁定視覺化模擬器

即時模擬 Python 物件引用機制
系統記憶體 (RAM Blocks) 模擬動態檢視：

變數命名與多重指定語法

# 多變數指定相同數值

a = b = c = 20

# 同一行指定多個變數 (Unpacking)

age, name = 18, "林大山"

# 刪除不使用的變數以釋放記憶體

del age

命名規則與保留字禁忌

  • 首字必須為大小寫英文字母、底線 _ 或中文。
  • 英文字母嚴格區分大小寫（Name 與 name 代表不同變數）。
  • 不可使用 Python 保留字：如 if, else, for, while, def, class, import, return, in, print 等。

2.2 資料型態 (Data Types) 與強制轉型

int

整數型態

不含小數點的整數（如 `100`, `-5`）。Python 整數精確度不受 32/64 位元限制。

float

浮點數型態

包含小數點的實數（如 `3.14159`, `12.0`）。

bool

布林值型態

僅有 `True` 與 `False` 兩個值（注意首字母大寫），用於條件判斷。

str

字串型態

以單引號或雙引號包覆之文字序列（如 `"Python"`）。

常見字串脫逸字元 (Escape Characters)

\n : 換行 (Newline)
\t : Tab 定位鍵
\\ : 顯示反斜線 \
\" : 顯示雙引號 "

檔名: ch02_trapezoid_area.py

# -*- coding: utf-8 -*-
"""
檔名: ch02_compound_interest.py
說明: 複利本金計算 (使用複合指定運算子 **= 與 *=)
"""

rate = 0.02   # 年利率 2%
years = 6     # 存款年數

deposit = float(input("請輸入本金存款金額: "))

# 計算複利倍數 (1 + rate) ** years
factor = (1 + rate) ** years
deposit *= factor

print(f"\n以年利率 {rate*100}% 計算")
print(f"{years} 年後複利本利和為: {deposit:.2f} 元")

# -*- coding: utf-8 -*-
"""
檔名: ch02_bmi_calculator.py
說明: 身高體重輸入與 BMI 格式化輸出

name = input("請輸入您的姓名: ")
height_cm = float(input("請輸入身高 (公分): "))

# 公分轉公尺並計算 BMI = 體重 / (身高m ** 2)
height_m = height_cm / 100
bmi = weight_kg / (height_m ** 2)

print(f"\n{"健康檢測簡報":=^30}")
print(f"姓名: {name}")
print(f"身高: {height_cm:.1f} cm | 體重: {weight_kg:.1f} kg")
print(f"您的 BMI 計算數值為: {bmi:.2f}")
